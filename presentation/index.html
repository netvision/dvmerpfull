Management Briefing · 2026

Lesson Plan Platform

A centralised digital system for organising, managing, and delivering structured lesson plans across all classes and subjects.

Confidential — Internal Use Only
The Problem

What challenges does this solve?

📂

Scattered Lesson Plans

Lesson plans stored in disconnected Excel files across multiple teachers with no central access point.

🔄

Manual Updates

Any change to a syllabus requires manually editing spreadsheets and redistributing them to all staff.

🔒

No Access Control

No way to restrict who can edit which subject — any teacher could modify any content.

👁️

No Visibility

Management has no real-time view of what lessons, concepts, or learning outcomes are being planned.

The Solution

One Platform. Multiple Roles. All Subjects.

🌐

Public View

Anyone can browse the lesson structure — classes, subjects, chapters, and learning outcomes — without logging in.

🔏

Teacher & Mentor Portal

Logged-in staff manage their assigned subjects, review content, provide feedback, and track progress across the platform.

👑

Admin Control

Admins manage all users, roles, subjects, and assignments — with full read/write access to every class and subject.

Powered by AI

Teachers get access to an integrated AI assistant — right inside the platform — running on the school's own local AI server. No data leaves the premises.

🔍

Topic Research

Ask the AI to explain a concept, summarise background material, or suggest age-appropriate analogies for any topic in any subject.

📝

Content & Outcomes

Generate draft learning outcomes, lesson summaries, key takeaways, and classroom activity ideas — then edit and save them directly into the chapter.

📋

Generate Bloom's-aligned questions across all six cognitive levels — from recall to evaluation — for any concept's learning outcomes.

🎨

Illustrations & Visuals

Describe a concept and generate or find a relevant illustration, diagram prompt, or visual reference to attach directly to the lesson.

Local AI Server — On-Premises
🧠 Ollama
or
🏠 LM Studio
  • No data sent to cloud — all inference runs on school hardware
  • Works offline — no internet dependency for AI features
  • School controls which model to run — swap anytime
  • Platform connects via standard local API — no lock-in
Key principles
  • AI assists, teachers decide — no content is saved without teacher review
  • All AI output is editable before it enters the curriculum database
  • Content stays within the school's curriculum context — grounded, not generic
  • Saves hours of research per teacher per week

Security

Data is protected at every level

🔐

JWT Authentication

Login issues a secure token stored in the browser. Every request is verified — no token means no access to protected data.

🛡️

Role-Based Permissions

Admins control everything. Teachers can only touch their assigned subjects. Public users can only read.

🔑

Hashed Passwords

Passwords are never stored in plain text. Only a one-way cryptographic hash is kept in the database (bcrypt).

🚧

Subject-Level Guard

Even if a teacher knows another subject's ID, the server refuses access — permission is enforced server-side.

Feedback System

A built-in loop for continuous improvement

How feedback flows
🧑‍🏫

Teacher adds or updates content

Chapters, concepts, outcomes, and activities are entered directly in the platform.

↓
🧑‍💼

Mentor reviews & leaves feedback

Mentors comment on specific concepts or chapters — suggestions, corrections, or approvals.

↓
📋

Curriculum Incharge tracks trends

Gets a bird's-eye view of feedback across all subjects — identifies gaps and patterns.

↓
✅

Teacher acts on feedback

Revises content based on mentor comments. The cycle repeats every academic period.

What the system enables

📌 Concept-level comments

Feedback is attached to the exact concept or chapter it refers to — no ambiguity, no lost emails.

🔔 Notifications

Teachers are notified when a mentor leaves feedback. Mentors are notified when a teacher responds or updates content.

📊 Feedback Status Tracking

Feedback items are marked Open, In Progress, or Resolved — giving Curriculum Incharge a clear completion picture.

🗂️ Full Audit History

Every comment, reply, and content change is timestamped and stored — a permanent record of curriculum evolution.

📄

Long Answer / Essay

Rubric-based grading aligned to Evaluate & Create levels. Teacher marks with criteria.
