Live Demo Script

Step-by-Step (12 Minutes)

Part A: Consumption Flow (5 min)

  • Open Home and pick one class
  • Open one subject and one chapter
  • Read concept learning outcome block
  • Open Exhibit modal and test media
  • Resize modal and click outside to prove persistence

Part B: Authoring Flow (7 min)

  • Login to portal and open chapter edit
  • Edit one concept using rich text and table
  • Upload one inline image in editor
  • Add or reorder one exhibit field
  • Save and verify immediately in public view

Confidence close: "What you edit is what learners see, with no extra formatting work."

Q and A Prep

Likely Questions from Teachers

Can I paste from Word?

Yes. Most formatting is preserved. You can quickly clean styles using the clear-format option if needed.

Can I add teaching resources?

Yes. Add links, uploaded media exhibits, and structured text in concept sections, including teaching methods/materials fields.

What if media is large?

Images are responsive, and media plays inside the exhibit modal. Recommend compressed files for faster classroom loading.

Operational tip: keep one chapter preloaded before the meeting to avoid network delays during first demo click.
